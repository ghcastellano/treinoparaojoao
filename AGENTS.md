# Mundo do João
Goal: working private family learning app, GitHub + Vercel + Neon, verified end to end.
Apply Karpathy simplicity: state assumptions, minimum necessary code, focused changes, measurable completion.
Commands: npm run dev, npm run lint, npm run typecheck, npm test, npm run build.
No diagnosis, IQ/percentiles, age-equivalent scores, speed rewards, advertisements or child data in client logs.
All personal data and every mutation require server authentication. Parent data/settings require fresh parent auth.
Never weaken authentication to fix a deployment. Never delete external projects without confirmed ownership, dependencies and recoverability.
Curriculum uses original educational items, not psychometric test reproductions. App-specific progression is an unvalidated educational heuristic.
Database optimistic concurrency and idempotency must be maintained. Test retries, wrong answers, hints, expiry and cross-session learning.
Finished means production browser -> API -> Neon -> restored browser state verified. Build success alone is insufficient.
